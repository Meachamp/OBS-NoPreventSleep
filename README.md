# OBS-NoPreventSleep
Prevents OBS from keeping the computer awake. Currently only supports Windows x64.

## Installation
1. Download the latest `obs-nopreventsleep.zip` from [Releases](https://github.com/Meachamp/OBS-NoPreventSleep/releases)
2. Extract the archive
3. Drop the extracted `obs-nopreventsleep.dll` into `C:\ProgramData\obs-studio\plugins\obs-nopreventsleep\`
4. Open OBS → Tools → Plugin Manager → Ensure the plugin is ON with no errors
